# 对标作品功能拆解

对标拆解服务于一个具体创作决策，例如“开篇如何建立职业困境”或“卷终怎样结算双线冲突”。拆功能，不搬情节；样本不能替代本书事实、人物欲望和题材契约。

本文件适合一次决策或少量样本。需要扫榜选样、分阶段处理整部作品、断点续跑、标准拆文库和下游召回时，改用 [market-scan.md](market-scan.md) 与 [deconstruction-pipeline.md](deconstruction-pipeline.md)。

## 1. 锁定决策问题

先写一句：

```text
本次拆解要帮助决定 ______，不用于复制 ______。
```

问题过大时拆成开篇承诺、冲突发动、信息释放、人物功能、单元结算或叙事声音中的一项。没有决策问题就不做大规模拆书。

## 2. 选择合法样本

只使用用户提供、用户有权访问或合法公开可读的文本。记录作品、版本、章节与取样理由；无法读取正文时不能根据简介、评论或记忆伪造逐章结论。

根据决策问题从不同功能位置抽样：开篇、普通推进章、转折章、高潮章、低压章、卷尾。一本作品的偶然写法不能当成平台规则；多个样本出现的共同点也只先作为假设。

## 3. 建立功能矩阵

| 样本位置 | 读者承诺 | 主角驱动 | 阻力来源 | 信息释放 | 情绪兑现 | 人物功能位 | 场景因果 | 状态变化 | 章尾债务 | 语言 / 叙事距离 |
|---|---|---|---|---|---|---|---|---|---|---|
| 作品A 第N章 |  |  |  |  |  |  |  |  |  |  |

每个判断附章节位置或短证据。描述“做了什么功能”，不要只写“节奏好”“很爽”“有电影感”。

## 4. 拆剧情单元

对与问题最相关的单元使用同一条因果链：

```text
入口压力 -> 人物欲望 -> 阻力 -> 选择 -> 代价 -> 状态变化 -> 新债务
```

另外标出：

- 哪些前置事实使选择成立。
- 情绪来自哪项得失或认知变化。
- 结果归属于谁，是否保持主角能动性。
- 若删去标志性表达，仍然可迁移的结构功能是什么。

## 5. 分离功能与表达指纹

**可迁移功能**包括：信息差的用途、冲突升级条件、关系压力类型、场景状态变化、承诺延期与兑现方法。

**不可迁移的表达指纹**包括：专名、独特世界规则、连续事件顺序、标志性场景组合、具体反转、角色关系排列、原句、独特比喻和可识别句法。不能以“只换名字”规避这一边界。

## 6. 重映射到本书

```markdown
| 原作功能 | 本书当前需求 | 新因果机制 | 本书人物为何这样选择 | 代价与结果 | 相似性风险 / 处理 |
|---|---|---|---|---|---|
| 制造公开评价压力 | 主角必须决定是否暴露能力 | 行业评审规则与合同期限 | 保护团队成果但承担违约风险 | 获得资格、失去客户 | 不使用原作比赛、台词和反转顺序 |
```

重映射必须改变因果材料和人物选择，不能只替换场景装饰。无法回答“为什么只有本书的人物会这样做”时，方案仍过于依赖原作。

## 7. 原创性复核

- 不保留专名、原句、标志性物件和独特设定组合。
- 不复现一串连续事件及其相同转折顺序。
- 不让本书人物为抵达原作桥段而违背既有动机。
- 不用多个来源拼贴出仍可识别的场景。
- 能从本书已建立的欲望、规则、关系和资源独立推导新方案。

最终只把“本书适用的功能结论、适用条件、风险和验证方式”写入规划。对标作品内容不进入事实库，也不进入正文。
