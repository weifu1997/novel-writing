# 文风契约与自然叙事

“去 AI 味”不是随机制造瑕疵，而是让每句话来自特定人物、特定处境和特定叙述选择。自然感是因果与视角的结果，不是句长方差或口语词数量。

## Style Contract

正文前用下列维度建立一份简短契约。用户自己的样章、本书已确认章节和明确要求是证据；平台通用偏好只能做兜底。有样章时必须从样章提取，不得用平台口味覆盖。

```markdown
- 视角/人称/时态：
- 叙事距离：贴身限知 / 中距离 / 全知，以及允许的切换方式
- 叙述声口：正式度、地域/时代词汇、幽默或冷峻程度
- 句段节奏：什么场景压短，什么场景允许长句/长段
- 对话声纹：主要人物各自的目的、回避方式、词汇和节奏
- 意象来源：角色职业、生活经验和世界观中自然会注意什么
- 信息策略：哪些直说，哪些让读者从证据推断
- 明确禁忌：用户点名不要的词、结构、标点或叙述习惯
```

不要把样章提炼成几十条打卡指标。选 5-8 个真正区分本书的维度，并在冲突时服从当前场景功能。

## 常见机器感及根因

### 1. 证据后再讲一遍结论

角色已经摔杯、改口或离开，叙述又补“可见他十分愤怒”。删掉结论通常更有力。首次出现的新规则仍要给读者可理解的锚，但用人物当下碰到的作用或后果，不集中讲说明书。

### 2. 库存微动作轮换

“深吸一口气、眸光微闪、嘴角勾起、指节泛白”被当作通用情绪标签。先做删除测试；动作若不改变选择、空间、物件或他人反应，多半可以删。不要仅换一个身体部位。

### 3. 情绪只有标准答案

人物总按最合理的顺序理解、愤怒、释然，像分析报告。让情绪通过选择暴露：嘴上答应却把钥匙带走，想解释却先问了钱，害怕时仍护住会惹祸的东西。矛盾必须来自人设和利益，不是随机反常。

### 4. 句段过齐

连续同长度段落、三项排比和机械长短交替都会显得设计痕迹重。按镜头、动作完成和信息转折自然断段。高潮可以短，推理、暧昧和氛围需要足够承接；不要全篇单句段，也不要为参差硬拆句。

### 5. 所有人说同一种话

对话差异不靠人人一个口头禅。区分其目的与策略：谁正面索取，谁用问题回避，谁先谈规则，谁只谈具体损失，谁在压力下话更多或更少。删去不产生反应的寒暄和互相解释已知信息。

### 6. 通用“精致”细节

无关的气味、触觉、杯沿、袖口并不会自动增加人味。细节至少完成一项功能：限制动作、暴露经验、改变判断、携带关系历史、埋下可回收信息。优先写视角人物因职业、欲望和偏见才会注意的东西。

### 7. 叙述者抢答

“他不知道的是”“这意味着”“命运的齿轮”“真正的风暴才刚开始”替人物和读者总结。章尾优先停在选择、代价、具体异常或未完成动作上。全知叙事可越过单一人物认知，但仍需符合已经确立的叙述姿态。

### 8. 监控录像式动作

把拿、放、转身、开门逐步记录，会消耗篇幅而没有叙事重量。保留改变空间关系、表现犹豫或触发后果的动作，其余合并。

## 去味时的语言扫描

专轮去味按下列指纹定位，不把次数、百分比或参差公式当成通过线。本书 Style Contract 和场景功能优先。

1. **工整句式**：连续同构长句、三项排比、机械长短交替。按镜头和信息转折改，不为三长一短硬拆。
2. **形容词并排**：美丽而优雅一类并列标签。能删一个就删，留下的换成可看见的动作或后果，不另造比喻。
3. **情绪直说**：他非常愤怒、可见他很紧张。优先删结论；只在结论承担信息功能时，改成已经发生的选择、身体后果或他人反应。不要给每个情绪配一套库存动作。
4. **总结收尾**：段末或章末升华、总之、综上、由此可见、仿佛在诉说、让人不禁。删解释，停在动作、未完成选择或具体异常上。原章若没有钩子，只报告，不补新威胁或半揭身份。
5. **库存循环词**：眼眸、嘴角、缓缓、微微一怔、深吸一口气。同一瞬间重复则删；有人物声线或必要功能则保留，不定章内配额。
6. **逻辑过顺**：把已知信息再讲一遍，问答像说明书。可省略双方已知道的内容，允许符合人物策略的回避或答非所问；不得跳过使选择成立的因果步。
7. **可互换对话**：遮住名字后谁都能说。用目的、回避和压力下的多少话来区分，不给每人派口头禅，不群加语气词。长台词按反应自然切开，不套 30 字上限。
8. **段落过齐**：连续多段接近等长。按动作完成和信息转折断段；关键动作或台词可以独立成段，不为参差把完整推理链拆成提纲。

核心手法：能用证据、动作和后果完成的，不让叙述者代讲结论。

## 局部返修法

去味与文风返修服从 [review-protocol.md](review-protocol.md) 的接受闸门、对照表和 diff 预算：只改已接受 findings，目标句及其前后各一句；没有对照表不得改文件。

每个疑似问题按此顺序处理：

1. 这句新增了什么：事实、视角、关系、情绪转折、节奏或伏笔？
2. 删除后无损就删除，不用同义句补回。
3. 有功能但表达泛化，就回到人物的当下目标、可知信息和物理后果重写。
4. 相邻句若表达同一件事，保留最具体、最贴视角的一次。
5. 通读前后两段，确认返修没有造成电报体、主语不明或因果跳步。
6. 写入对照表：`finding_id -> 原句 -> 删/改/保留 -> 改后文本或理由`。说不清功能则保留。

修法会改情节、关系、视角或伏笔时停止去味，交回审稿裁决。

## 不设通用硬指标

对话占比、句长、段长、爽点密度和钩子类型随题材、章节定位和既定风格变化。工具数据可帮助定位异常，但不能证明好坏，更不能证明“真人写作”。以下做法禁止：

- 用一个 0-100 的“AI 味指数”决定是否可交付。
- 为降低检测分数故意加错字、脏话、口头语或无关闲笔。
- 禁用所有“仿佛、然而、很、的、了、说”等正常词。
- 机械要求每 300 字新信息、每章一个打脸、固定比例对话、段长上限、句长交替公式或章内库存词配额。
- 去味时补钩子、补爽点、加人设口癖或改章末走向。
- 把“展示而非讲述”绝对化；时间跳跃、次要信息和明确判断可以简洁讲述。

`prose_lint.py` 只是候选定位器。命中项有明确人物声线、修辞目的或必要信息功能时，记录已复核并保留。改 lint 规则前先跑 `tests/fixtures/prose-lint-regression.json` 对应测试；样本管规则回归，不管语境去留。
