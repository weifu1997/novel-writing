# 平台与篇幅 Profile

这些 profile 是写作侧的默认假设，不是算法真相、合同建议或爆款保证。用户的作品定位和真实后台数据优先。平台规则、收益门槛、活动、AI 政策和推荐机制会变化；涉及数字或资格时查询带日期的官方来源，并把不确定项标明。

## 通用网文

- 优先建立清楚的读者承诺、持续冲突源和可增长的人物关系。
- 开篇尽早让人物面对具体问题，但不强制第一句打架、50 字打脸或前三章塞完世界观。
- 章节结尾提供继续阅读的理由；低压章可以用关系变化、阶段目标或新理解收束。
- 节奏来自兑现与新债务交替，不等于每章重复同一套“压制-反杀”。

## 番茄方向

适合将其视为移动端、免费阅读和广泛读者场景下的 profile：

- 进入场景快，首屏能辨认人物、处境和异常；减少开篇集中解释。
- 语言清楚、行动和对话可视化，重要情绪回报不要拖得没有阶段兑现。
- 章末关注下一页动力，但钩子类型轮换，避免每章都靠突然来电、身份曝光。
- 真实完读、留存和评论反馈可用于调整后续细纲；没有数据时不编造指标。
- “黄金三章”“前 200 字”等可作为检查窗口，不是让所有题材套同一公式。

## 七猫方向

同样偏移动端连续阅读，可强调直接冲突、清晰关系与稳定更新：

- 每章最好有状态进展或小兑现，纯铺垫需要同时改变信息或关系。
- 强情绪题材可提高冲突和回报频率，但悬疑、年代、家庭或治愈题材不强制打脸词汇。
- 对话与场面应便于想象，不为了所谓短剧感把人物写成只会喊口号。
- 分享金句、固定“欺-打-悬”和每章爆点只能按作品需要选用，不能设为普遍硬门槛。

## 起点方向

可将其视为长篇付费连载与核心类型读者 profile：

- 重视核心机制的长线可扩展性、升级台阶、世界规则和阶段结算。
- 每章提供可感知价值：推进、发现、策略、关系或能力变化，而不只卡断。
- 金手指/核心机制应有边界、代价和新问题，避免一次性解决长期矛盾。
- 付费节点前后的兑现节奏、卷末结算和长期伏笔需要整体规划。
- 发布合规以起点当期官方规则为准，不声称“改写七成”或某个检测分数必然合规。

## 短篇与故事平台

- 用一个核心支点承载主要情绪或认知变化，减少人物、世界观和支线。
- 开头迅速建立欲望、异常或关系压力；中段每次反转都重解释前文，而非只加新秘密。
- 结尾完成主情绪闭环并保留余韵，不照搬长篇的强制续读坑。
- 第一或第三人称由题材和文风决定，不把第一人称当成绝对规则。

## 用数据迭代

先定位读者在哪个承诺上流失，再改对应层级：

- 开篇离开：检查承诺是否清楚、场景是否进入太慢、信息是否难懂。
- 中段离开：检查重复冲突、兑现不足、选择无代价、关系没有变化。
- 章末离开：检查本章是否真正产生变化，以及下一章债务是否具体。
- 评论分化：区分“人物引发讨论”和“因果没写清”；前者可保留，后者要修。

数据只能说明现象，不能单独证明原因。一次只改最可能的变量，并观察后续样本。
